# 🏠 Умный дом на базе Raspberry Pi

Проект умного дома с автоматическим управлением освещением и системой безопасности.  
Работает как на реальной **Raspberry Pi**, так и в **эмуляторе**, используя файловую эмуляцию GPIO.

## 📌 Описание проекта

Проект реализует базовую систему умного дома со следующими возможностями:

- автоматическое управление освещением;
- обнаружение движения;
- отправка уведомлений в Telegram;
- логирование событий.

Система написана на языке **Go** и ориентирована на модульность и переносимость.

---

## ⚙️ Основной функционал

### 💡 Управление освещением
- считывание уровня освещённости;
- автоматическое включение/выключение света при достижении порогового значения.

### 🚶 Датчик движения
- отслеживание движения;
- отправка уведомлений в Telegram;
- запись событий в лог-файл.

### 📝 Логирование
- все события фиксируются в `logs/security.log`.

---

## 🧩 Используемые технологии

- Go
- Raspberry Pi (или эмуляция)
- GPIO (через файловую систему)
- Telegram Bot API

## 📁 Структура проекта

```text
smart-home-iot/
├── config/
│   ├── config.json          # Общие настройки
│   └── config.local.json    # Секретные данные (токен, chat_id)
├── gpio/
│   ├── temperature.txt     # Температура
│   ├── illumination.txt    # Освещённость
│   ├── light.txt           # Состояние света
│   └── motion.txt          # Датчик движения
├── logs/
│   └── security.log        # Логи событий
├── cmd/
│   └── smarthome/
│       └── main.go         # Точка входа
└── README.md

Лицензия

Проект распространяется под лицензией MIT. См. файл LICENSE для подробностей.

Пояснения:

Структура проекта:

config: содержит файлы конфигурации для проекта и секретные данные (токен и chat_id для Telegram).

gpio: папка для хранения данных от сенсоров (температура, освещенность, движение).

logs: папка для логов, где будут записываться события, например, срабатывания датчиков.

cmd/smarthome/main.go: главный файл программы с логикой работы.

Как запустить:

Клонируй репозиторий.

Настрой конфигурационные файлы.

Запусти программу с помощью Go.

Как использовать:

Программа будет следить за уровнем освещенности и включать/выключать свет в зависимости от показаний сенсоров.

При срабатывании датчика движения отправляется уведомление в Telegram.

Дополнительные рекомендации:

Ты можешь настроить запуск программы при старте системы (если работаешь с Raspberry Pi) с помощью cron или systemd.

Для тестирования проекта можно использовать эмуляторы Raspberry Pi и GPIO, чтобы не подключать физические устройства.
