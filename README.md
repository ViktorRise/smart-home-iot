Умный дом на базе Raspberry Pi

Проект представляет собой систему умного дома с управлением освещением и мониторингом безопасности. Основной функционал включает в себя:

Контроль уровня освещенности.

Управление светом в зависимости от уровня освещенности.

Оповещение через Telegram при обнаружении движения.

Описание проекта

Проект был реализован для демонстрации возможностей Internet of Things (IoT) с использованием платформы Raspberry Pi и эмулятора. Система контролирует освещенность в помещении с использованием датчиков и автоматически включает или выключает свет в зависимости от значений освещенности. Также реализовано уведомление в Telegram, когда срабатывает датчик движения.

Требования

Raspberry Pi (или эмулятор Raspberry Pi).

Go (для разработки).

Установленный Telegram Bot для уведомлений.

Установка
1. Клонируйте репозиторий:
git clone https://github.com/yourusername/smart-home-iot.git
cd smart-home-iot

2. Настройка конфигурации:

Создайте файл config/config.local.json для хранения секретных данных (например, токен Telegram Bot и chat_id).
{
  "telegramBotToken": "your-telegram-bot-token",
  "telegramChatId": 123456789
}
Установка зависимостей:

3. Для работы проекта необходимо иметь установленный Go. Чтобы проверить установку Go, выполните:
go version

4. Запуск:

После настройки конфигурации, запустите программу:
go run ./cmd/smarthome

Описание функционала

1. Управление освещением

Программа автоматически управляет освещением, включая или выключая свет в зависимости от уровня освещенности. Настроен порог освещенности для включения/выключения света.

2. Оповещения через Telegram

Программа отправляет уведомления в Telegram, когда срабатывает датчик движения.
