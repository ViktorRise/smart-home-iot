# 🏠 Умный дом на базе Raspberry Pi

Проект умного дома с автоматическим управлением освещением и системой безопасности.  
Работает как на реальной **Raspberry Pi**, так и в **эмуляторе**, используя файловую эмуляцию GPIO.

## 📌 Описание проекта

Проект реализует базовую систему умного дома со следующими возможностями:

- автоматическое управление освещением;
- обнаружение движения;
- отправка уведомлений в Telegram;
- логирование событий.

Система написана на языке **Go** и ориентирована на модульность и переносимость.

---

## ⚙️ Основной функционал

### 💡 Управление освещением
- считывание уровня освещённости;
- автоматическое включение/выключение света при достижении порогового значения.

### 🚶 Датчик движения
- отслеживание движения;
- отправка уведомлений в Telegram;
- запись событий в лог-файл.

### 📝 Логирование
- все события фиксируются в `logs/security.log`.

## 🚀 Установка и запуск

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/yourusername/smart-home-iot.git
cd smart-home-iot
```

### 2️⃣ Настройка конфигурации

Создайте файл `config/config.local.json`:

```json
{
  "telegramBotToken": "YOUR_BOT_TOKEN",
  "telegramChatId": 123456789
}
```

> ❗ Файл `config.local.json` **не должен попадать в GitHub** (добавлен в `.gitignore`).

---

### 3️⃣ Запуск программы

```bash
go run ./cmd/smarthome
```

После запуска:
- система начнёт отслеживать освещённость;
- при движении отправит сообщение в Telegram;
- все события будут записаны в лог.

---

## 🧪 Тестирование без реального железа

Проект поддерживает эмуляцию GPIO через файлы:

- можно вручную менять значения в `gpio/*.txt`;
- программа реагирует так же, как на реальной плате.
