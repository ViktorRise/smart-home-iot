# Умный дом на базе Raspberry Pi

Проект представляет собой систему умного дома, которая контролирует освещенность в помещении с использованием датчиков и автоматически включает или выключает свет в зависимости от уровня освещенности. Также предусмотрена система уведомлений через Telegram при обнаружении движения.

Описание проекта

Проект был реализован с использованием платформы Raspberry Pi (или её эмулятора) для создания системы управления умным домом. Система включает в себя:

Контроль освещенности в помещении.

Управление светом в зависимости от уровня освещенности.

Оповещение через Telegram, когда срабатывает датчик движения.

Особенности

Telegram-уведомления при обнаружении движения.

Автоматическое включение и выключение света в зависимости от уровня освещенности.

Логирование всех событий в файл.

Требования

Raspberry Pi или эмулятор Raspberry Pi.

Go для разработки и запуска программы.

Установленный Telegram Bot для получения уведомлений.

GPIO порты для работы с датчиками (или эмуляция).

Установка
1. Клонирование репозитория

Для начала клонируй репозиторий с GitHub:

git clone https://github.com/yourusername/smart-home-iot.git
cd smart-home-iot

2. Настройка конфигурации:

Создайте файл config/config.local.json для хранения секретных данных (например, токен Telegram Bot и chat_id).
{
  "telegramBotToken": "your-telegram-bot-token",
  "telegramChatId": 123456789
}
Установка зависимостей:

3. Для работы проекта необходимо иметь установленный Go. Чтобы проверить установку Go, выполните:
go version

4. Запуск:

После настройки конфигурации, запустите программу:
go run ./cmd/smarthome
Программа будет автоматически управлять светом в зависимости от уровня освещенности и отправлять уведомления в Telegram при срабатывании датчика движения.

Описание функционала

1. Управление освещением

Программа автоматически управляет освещением, включая или выключая свет в зависимости от уровня освещенности. Настроен порог освещенности для включения/выключения света.

2. Оповещения через Telegram

Программа отправляет уведомления в Telegram, когда срабатывает датчик движения.

Структура проекта

smart-home-iot/
├── config/
│   ├── config.json           # Общие настройки проекта
│   └── config.local.json     # Конфигурация для токена и chat_id
├── gpio/
│   ├── temperature.txt       # Температурные данные
│   ├── illumination.txt      # Данные освещенности
│   ├── light.txt             # Состояние света (включён/выключен)
│   └── motion.txt            # Данные с датчика движения
├── logs/
│   └── security.log          # Логи с событиями (например, движение)
├── cmd/
│   └── smarthome/
│       └── main.go           # Основной файл с логикой программы
└── README.md                 # Документация проекта

Пояснения:

Структура проекта:

config: содержит файлы конфигурации для проекта и секретные данные (токен и chat_id для Telegram).

gpio: папка для хранения данных от сенсоров (температура, освещенность, движение).

logs: папка для логов, где будут записываться события, например, срабатывания датчиков.

cmd/smarthome/main.go: главный файл программы с логикой работы.

Как запустить:

Клонируй репозиторий.

Настрой конфигурационные файлы.

Запусти программу с помощью Go.

Как использовать:

Программа будет следить за уровнем освещенности и включать/выключать свет в зависимости от показаний сенсоров.

При срабатывании датчика движения отправляется уведомление в Telegram.

Дополнительные рекомендации:

Ты можешь настроить запуск программы при старте системы (если работаешь с Raspberry Pi) с помощью cron или systemd.

Для тестирования проекта можно использовать эмуляторы Raspberry Pi и GPIO, чтобы не подключать физические устройства.
