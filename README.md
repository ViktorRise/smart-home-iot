\## Тема проекта

Система управления умным домом с модульной архитектурой.



Проект включает:

\- управление освещением;

\- контроль температуры;

\- элементы системы безопасности.



\## Аппаратная платформа

Проект ориентирован на платформу \*\*Raspberry Pi\*\* или аналогичную встраиваемую ЭВМ под управлением Linux.



Физическая плата отсутствует.  

Используется \*\*эмуляция среды Raspberry Pi\*\* (виртуальная машина / Linux-среда).



\## Эмуляция GPIO

Работа с портами ввода-вывода GPIO эмулируется через файловую систему.



Состояние виртуальных датчиков и исполнительных устройств хранится в файлах:

\- температура;

\- освещение;

\- датчики движения.



Чтение и запись в файлы имитирует работу с GPIO.



\## Программная реализация

Язык программирования: \*\*Go (Golang)\*\*



Используются:

\- работа с файловой системой;
